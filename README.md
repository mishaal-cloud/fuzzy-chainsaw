## Projects

### Google Ads Automation
A comprehensive framework for automating Google Ads analysis and updates using the Google Ads API.

**Location**: `google-ads-automation/`

**Features**:
- Extract and analyze campaign, keyword, and ad performance data
- Identify underperforming keywords automatically
- Pause/enable campaigns and keywords programmatically
- Update budgets and bids based on performance
- Add negative keywords
- Export detailed reports to CSV

**Quick Start**:
```bash
cd google-ads-automation
pip install -r requirements.txt
python examples/simple_query.py
```

See the [Google Ads Automation README](google-ads-automation/README.md) for full documentation
